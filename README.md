# Panier

Application de liste de courses partagée, construite avec TanStack Start, React, Vite et Supabase.

## Développement local

Vous avez besoin de Node.js 22.12 ou plus récent et de npm.

```sh
git clone <repository-url>
cd list-together
npm install
npm run dev
```

## Scripts

```sh
npm run build
npm run test
npm run lint
```

## Technologies

- TanStack Start
- TypeScript
- React
- Tailwind CSS
- Supabase
